CONNECTION HELP

HOW TO CONNECT TWO DEVICES:

  1. On one device, click Create Room. A 4-digit code will appear.
  2. On the second device, click Join Room and enter that code.
  3. Both devices will connect instantly and start the live typing race!
  4. You can also copy the room code and share it with friends via chat.
ONLINE MODE: This game runs live on Render using Socket.io. Both players need internet access to race in real-time!
